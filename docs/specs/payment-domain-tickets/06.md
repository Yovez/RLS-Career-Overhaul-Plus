## What to build

Life-cost spends (fines, fuel, repairs, insurance, loans, property) go through the Payment Domain facade with the correct spend buckets when auto-pay is claimed, so checking covers those costs when configured.

## Acceptance criteria

- [ ] Each listed life-cost path pays via the payment facade (no wallet-only bypass for money lines)
- [ ] Reasons map to the intended spend buckets (fines, fuel, repairs, insurance, loans, property)
- [ ] Auto-pay claimed for a bucket: canPay/pay use that checking Account
- [ ] Auto-pay off: Wallet-only for that bucket
