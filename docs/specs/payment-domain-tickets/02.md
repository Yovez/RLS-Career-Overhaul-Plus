## What to build

Make vehicle dealership buying coherent end-to-end under Payment Domain: with vehicles auto-pay on, list, filters, checkout, and the real purchase all agree on Spendable for the vehicle purchase reason, and debit uses checking then Wallet. With auto-pay off, gates and pay use Wallet only.

## Acceptance criteria

- [ ] Vehicles auto-pay on + low Wallet + enough checking: listings/filters show the vehicle as affordable when Spendable covers it
- [ ] Same setup: checkout and purchase succeed; checking then Wallet debit matches the facade
- [ ] Vehicles auto-pay on + insufficient Spendable: UI and purchase both refuse
- [ ] Vehicles auto-pay off: affordability and pay use Wallet only
- [ ] Wallet display / deposit capacity in related UI is not overwritten with Spendable
