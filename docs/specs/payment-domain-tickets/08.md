## What to build

Bank and deposit UIs show true Wallet and Account balances. Spendable never leaks into deposit capacity or Account displays, so players cannot "deposit" money that already includes the same checking balance.

## Acceptance criteria

- [ ] Deposit capacity uses Wallet only
- [ ] Account balance displays show real Account balances
- [ ] Turning vehicles (or any) auto-pay on does not inflate deposit or Wallet display via Spendable
- [ ] Financial history remains Wallet ledger truth (not rewritten as Spendable)
