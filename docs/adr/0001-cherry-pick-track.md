# Cherry-pick-track over merge-track

Plus is a Life Sim product built from Upstream RLS, not a tracking fork. We read public Upstream RLS releases and port only Glue that Must-port (especially BeamNG version breaks) or gameplay that Fits Life Sim; Claimed Domains default to Plus Wins. We rejected bulk-merging release branches because it forces Plus to keep Upstream RLS’s system designs instead of owning Payment, Housing, Marketplace, Job Broker, and related loops.
